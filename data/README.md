# Input data

Download the following four processed files from NCBI GEO accession
GSE104609 (BioProject PRJNA413294) and place them here:

- GSE104609_ICC283_DESeq2.csv   (DESeq2 results, ICC283 sensitive)
- GSE104609_ICC8261_DESeq2.csv  (DESeq2 results, ICC8261 tolerant)
- GSE104609_ICC283_edgeR.csv    (edgeR results, ICC283 sensitive)
- GSE104609_ICC8261_edgeR.csv   (edgeR results, ICC8261 tolerant)

Source: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE104609
